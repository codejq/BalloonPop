# Voice clip credits

The clips in this folder were generated with [Piper](https://github.com/rhasspy/piper) text-to-speech
by `tools/generate_voices.py`. Only voices whose model card states an open licence are used.

| Language | Piper voice | Licence |
|---|---|---|
| English | en_US-ljspeech-medium | Public domain (LJ Speech dataset) |
| Spanish | es_ES-davefx-medium | CC0 |
| French | fr_FR-siwis-medium | CC BY 4.0 (SIWIS French Speech Synthesis Database, Yamagishi et al.) |
| German | de_DE-thorsten-medium | CC0 (Thorsten Müller) |
| Italian | it_IT-serena-medium | CC BY 4.0 |
| Portuguese | pt_BR-faber-medium | CC0 |
| Dutch | nl_BE-nathalie-medium | CC0 |
| Swedish | sv_SE-nst-medium | CC0 (NST dataset) |
| Russian | ru_RU-denis-medium | CC0 |

Indonesian and Arabic have no clearly licensed Piper voice, so the game uses the device's own
text-to-speech for them.
